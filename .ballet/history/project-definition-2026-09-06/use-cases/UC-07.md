# Check Action readiness

## Intent

Validation inspects first and decides whether existing evidence is sufficient, bounded Work is needed or a blocker must be exposed.

## Examples

- **Given** a pending Action, **when** Validation performs the precheck, **then** it returns only `done`, `delegate` or `blocked` with evidence.
- **Failure:** **Given** insufficient or contradictory evidence, **when** Validation evaluates readiness, **then** it cannot return `done`.

## Success goals

- Validation proves completion or bounds the next work before any write.

## Failure goals

- No false done or Work-first execution.

## Expected outcomes

- A strict evidence-backed precheck outcome.
