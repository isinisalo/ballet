# Describe and approve a Use Case

## Intent

An exact human-approved semantic revision is trustworthy project evidence without becoming an Environment execution gate.

## Examples

- **Given** a draft Use Case with acceptance intent, **when** the human approves its exact semantic hash, **then** the approval becomes project evidence without binding Environment execution.
- **Failure:** **Given** an approved Use Case, **when** its semantic content changes, **then** approval is invalidated without blocking unrelated Environment runs.

## Success goals

- Exact human-approved Use Cases remain trustworthy project evidence.

## Failure goals

- No stale approval survives a semantic edit.

## Expected outcomes

- An immutable approval record bound to one canonical content hash.
