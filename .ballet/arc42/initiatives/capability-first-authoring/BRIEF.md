# Capability-first Authoring BRIEF

## Purpose and authority

Implement `goal-018` / `REQ-018`: replace Graph/GraphNode upper-level planet canvases with capability-first card workspaces while preserving the Job industrial flow. The user authorized the implementation on 2026-08-23.

## Fact and decision

- **Fact CFA-F-001:** the old canvas emphasizes topology and cannot comfortably author state/outcome/cost/readiness data.
- **Decision CFA-D-001:** use URL-owned Capability/Decision Model and Jobs/Local Decision Model sections as proposed in ADR-029.
- **Hypothesis CFA-H-001:** card scanning and inline readiness reduce ambiguity for capability authoring; human usability review pending.

## Scope

Responsive cards, GraphNode/JobNode CRUD, atomic ID references, inline scoped decision editor, factual Run views and upper-level appearance/canvas cleanup. Job-flow visuals and tokens remain.

## Quality and acceptance

Priority-1 `QS-024` requires exact routes, keyboard/focus, no page overflow/clipped core action, CRUD/error states and 1/5/40 plus 1/17/64 scale evidence at 1440×900 and 390×844.
