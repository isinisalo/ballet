# Outcome-aware Hierarchical Policy PLAN

## Implementation slices

1. Define canonical intrinsic outcomes and structural draft versus Run-readiness schemas.
2. Compile scoped outcome-aware models with exact ppm sums, semantic result consistency and proper-policy analysis after guards.
3. Dispatch global GraphNode and local JobNode actions with one solver primitive and no strategy fallback.
4. Reproject actual state from canonical facts, persist expected distribution plus model-match class and solve again from actual state.
5. Snapshot model/capability/module provenance and validate restart/resume behavior.
6. Expose scoped Configure preview and Run policy/execution read models.
7. Validate tests, builds, module roundtrips, platform boundary, startup and browser flows.

## Stop conditions

Do not invent probability/cost inputs, run the pilot on an unapproved model, remove `agent_v1`, deploy, merge or push.
