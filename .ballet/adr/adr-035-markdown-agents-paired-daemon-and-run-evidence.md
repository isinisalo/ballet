[ADR-035: Run Evidence terminaalisen tuloksen projektiona]
Decision: Run Evidence muodostetaan omistavan terminaalisen Environment Runin runtime-faktoista sekä tarkoista commit- ja artefaktiviitteistä uudelleen laskettavana projektiona.
Scope: Koskee Runin tuloksen tarkastelua ja Criticin käyttämää evidenssiä. Run Evidence ei ole erillinen muokattava tuotemääritys tai rinnakkainen totuusvarasto.
