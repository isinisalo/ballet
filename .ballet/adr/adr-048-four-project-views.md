[ADR-048: Projektin neljä näkymää]
Decision: Projektin sisältö jaetaan Overview-, Event Storming-, User Stories- ja ADRs-näkymiin: Overview omistaa projektin tarkoituksen, User Story käyttäytymisen ja hyväksymiskriteerit, Event Storming prosessimallin ja ADR voimassa olevan arkkitehtuuripäätöksen.
Scope: Koskee repositoryn projektimäärittelyä ja tarinoiden semanttiseen sisältöön sidottua ihmishyväksyntää. Project Config tai Run ei ylläpidä rinnakkaista Direction-sisältöä.
