[ADR-041: Ohjeen määrittämä projektikonteksti]
Decision: Actionin instruction tai Skill määrää luettavat projektidokumentit; Overview, User Storyt, ADR:t ja Event Storming eivät kuulu automaattiseen Run-porttiin, snapshot-sisältöön tai prompt-injektioon.
Scope: Koskee projektin intention ja ajonaikaisen suorituksen rajaa. User Storyn hyväksyntä säilyy projektin evidenssinä ilman suoritusvaltaa.
