[ADR-047: Suora Markdown-muokkaus]
Decision: Overview, Instructions ja Skills käyttävät yhteistä Markdown-lähde-editoria, jonka tallennus ja ristiriitasuoja kohdistuvat kanoniseen repositorytiedostoon.
Scope: Koskee vapaamuotoisia Markdown-työtiloja ilman rinnakkaista esikatselua. User Storyt ja ADR:t käyttävät omia rakenteisia korttilomakkeitaan.
