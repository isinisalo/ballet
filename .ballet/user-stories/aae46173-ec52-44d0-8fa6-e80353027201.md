goal: käynnistää ja seurata Validationin ohjaamaa Environment Runia
benefit: työ etenee vain todennetun tuloksen perusteella
acceptanceCriteria:
  - given: Statejen edeltäjissä on pending, running tai blocked Action
    when: runtime valitsee seuraavan tehtävän
    then: myöhemmän Staten dispatchia ei tehdä
  - given: Action on ensimmäinen odottava työ
    when: Validation tekee precheckin
    then: tulos on vain done, delegate tai blocked; delegate sisältää rajatun Work-promptin
  - given: Validation delegoi työtä
    when: Work suorittaa tehtävän managed worktreessä
    then: Work palauttaa completed tai needs_input eikä hyväksy itseään tai valitse retryä
  - given: Work palauttaa tuloksen
    when: Validation tekee postcheckin
    then: tulos on vain done, retry tai blocked ja done perustuu riippumattomasti tarkastettavaan evidenssiin
  - given: maxRetries on 0, 2 tai 5
    when: Validation pyytää semanttisia retryjä
    then: Work-yrityksiä sallitaan vastaavasti yhteensä 1, 3 tai 6 ja korjauspalaute välitetään seuraavaan yritykseen
  - given: retry-budjetti loppuu tai Validation palauttaa blocked
    when: runtime käsittelee tuloksen
    then: Action ja yksi siihen sidottu Feedback-entry muuttuvat atomisesti blocked-tilaisiksi myös duplikaattituloksessa
  - given: provider epäonnistuu tai suoritus keskeytyy
    when: virhe käsitellään
    then: operatiivinen virhe ei muutu semanttiseksi retryksi tai virheelliseksi done-tulokseksi
  - given: Run on käynnissä
    when: peruutan sen
    then: provider peruutetaan eikä uusia tehtäviä dispatchata
  - given: käyttäjän checkoutissa on työtä
    when: agentti kirjoittaa
    then: muutokset kertyvät vain saman Runin hallittuun worktreehen ja myöhempi Work näkee aikaisemmat muutokset
  - given: Run päättyy blocked-, failed- tai cancelled-tilaan
    when: se finalisoidaan
    then: työtilaa säilytetään rajattua diagnostiikkaa varten eikä tulosta esitetä onnistuneena
  - given: Run on käynnistetty
    when: projektin määritys muuttuu
    then: käynnissä oleva Root Snapshot ja suoritussuunnitelma eivät muutu
