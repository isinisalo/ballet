# Form the final Run Evidence

## Intent

Terminal Run Evidence is a factual projection of canonical project and runtime truth.

## Examples

- **Given** every Environment Action is done and finalization succeeds, **when** the Run reaches terminal completion, **then** a Run Evidence projects commit, artifacts, statuses, approvals and evidence.
- **Failure:** **Given** the Environment is incomplete or blocked, **when** evidence data is requested, **then** no terminal Run Evidence is invented.

## Success goals

- The final evidence is factual, immutable and inspectable.

## Failure goals

- No provider prose or partial Run becomes a Run Evidence.

## Expected outcomes

- A recomputable terminal projection linked to canonical truth.
