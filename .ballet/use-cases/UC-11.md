# Run scheduled quality criticism

## Intent

Critic periodically evaluates immutable Run Evidence without writing or approving anything.

## Examples

- **Given** a disabled default Critic schedule, **when** the project loads, **then** no automatic provider Run starts.
- **Failure:** **Given** an enabled due occurrence with a valid lease, **when** Critic inspects the latest Run Evidence, **then** it produces at most one read-only proposal and no Feedback.

## Success goals

- Quality criticism is scheduled, non-overlapping and evidence-based.

## Failure goals

- No schedule overlap, write or autonomous approval.

## Expected outcomes

- An immutable Critic proposal awaiting a human decision.
