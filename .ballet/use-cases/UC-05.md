# Process State Actions by priority

## Intent

Runtime chooses exactly the first eligible Action in the first incomplete State.

## Examples

- **Given** a State with multiple Actions, **when** the runtime selects work, **then** it dispatches the lowest-priority-number pending Action.
- **Failure:** **Given** an earlier Action or State is not done, **when** later work is considered, **then** zero later Actions are dispatched.

## Success goals

- Action selection is deterministic and gate-safe.

## Failure goals

- No pending or blocked predecessor can be bypassed.

## Expected outcomes

- Ascending priority execution inside the first incomplete State.
