# Retry or block an Action

## Intent

Validation owns bounded semantic retry and creates visible atomic Feedback when the Action cannot progress.

## Examples

- **Given** Validation rejects completed Work while retry budget remains, **when** postwork returns `retry`, **then** one additional Work attempt receives the correction.
- **Failure:** **Given** the final allowed Work attempt still needs retry, **when** postwork is applied, **then** the Action and exactly one Feedback entry are committed atomically as blocked.

## Success goals

- Semantic retries are bounded and blockers stay visible.

## Failure goals

- No provider failure silently consumes semantic retry budget.

## Expected outcomes

- Done, a bounded retry, or atomic blocked Feedback.
