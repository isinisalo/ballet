# Delegate bounded work to a subordinate agent

## Intent

Work executes only Validation's bounded dynamic prompt in an isolated managed worktree.

## Examples

- **Given** Validation returns `delegate` with a bounded dynamic prompt, **when** runtime creates Work, **then** Work executes only that prompt in the managed worktree.
- **Failure:** **Given** Work attempts an approval or external write, **when** permissions are evaluated, **then** the operation is denied.

## Success goals

- Subordinate Work is isolated and explicitly scoped.

## Failure goals

- Work cannot route, approve or widen its permissions.

## Expected outcomes

- A completed or needs-input Work outcome for Validation to postcheck.
