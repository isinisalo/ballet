# Refine an Action and rerun immutably

## Intent

Refinement remains read-only until exact human approval and then creates a local commit plus immutable continuation lineage.

## Examples

- **Given** approved Feedback and a read-only exact-hash Refinement proposal, **when** the human approves the exact impact and apply succeeds, **then** one managed-worktree commit creates one immutable continuation Run.
- **Failure:** **Given** a stale preimage, forbidden path or incomplete shared Skill impact, **when** apply is attempted, **then** zero project files and zero continuation Runs are created.

## Success goals

- Approved refinement is exact, local and auditable.

## Failure goals

- No proposal writes, partial apply or parent-Run mutation.

## Expected outcomes

- A verified refinement commit and lineage-bound continuation Run.
