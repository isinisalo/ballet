# Define an Action

## Intent

An Action is one bounded, independently verifiable task with explicit role composition and retry limit.

## Examples

- **Given** one bounded capability is needed, **when** the human defines its task, evidence, retries, roles and resources, **then** Validation and Work receive an executable immutable composition.

## Success goals

- Every Action is bounded, resourced and independently verifiable.

## Failure goals

- No single Action represents the whole project.

## Expected outcomes

- An Action with exact Use Case references, instructions, Skills and retry limit.
