# React workspace accessibility

1. Read `DESIGN.md` and use its tokens and established React, Tailwind and shadcn primitives.
2. Let the canonical URL own workspace and entity identity; make invalid IDs and stale conflicts explicit and recoverable.
3. Render DTO facts without inventing progress, status, duration or approval. Never add force-done controls.
4. Use semantic headings, labels, visible focus, logical tab order and text or icon-and-text status cues.
5. At 1440×900 and 390×844, prevent page-level horizontal overflow and keep core actions visible; scroll code and diffs internally.
6. Test keyboard behavior, dirty-draft protection, route history, dialog consequences, reduced motion and both accepted viewports.
