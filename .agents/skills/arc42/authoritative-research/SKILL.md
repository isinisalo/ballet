# Authoritative research

1. Define the bounded question and affected QS/RISK/ADR/BB IDs before browsing.
2. Prefer official documentation, official release notes/advisories, standards and original research. Record direct URL, publisher and observation date.
3. Compare the source with the repository's current dependency/configuration and repeated validation or repair evidence.
4. Retain a Finding only when impact is material and state the expected measurable improvement.
5. Do not write to external systems, change permissions/topology/network, or alter accepted Goal/ADR/instruction/skill behavior.
6. If no material finding exists, report that result and make no semantic document change.
