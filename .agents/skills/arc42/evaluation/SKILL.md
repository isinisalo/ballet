# Evaluation

1. Select in-scope priority scenarios and compare their measurable criteria with actual evidence.
2. Record passed, failed, blocked and missing evidence separately; never infer success from absence of failure.
3. Analyze risk, debt, drift and whether relevant ADRs/concepts still achieve the intended response.
4. Create only evidence-backed Findings with impact, likelihood, affected stable IDs and a proposed capability/outcome.
5. Update section 11, TRACEABILITY, initiative REVIEW and METHOD-HEALTH only where the evidence changes status.
6. Route a material gap to the matching arc42 capability; return `needs_input` if more than one target remains equally justified.
