# Initiative handoff

1. State the initiative ID, current status and completed Node goal.
2. List changed artifact paths, stable IDs and checks/evidence without copying document bodies or logs.
3. Separate Decisions, Assumptions, Findings and Open questions.
4. Name exactly one next approved Loop/action when evidence supports it.
5. Describe a repair need as requested capability/outcome, never as continuation, return target or first-choice fallback.
6. Return `needs_input` when a human-owned decision or target distinction is missing; update the bounded `handoff` State fields.
